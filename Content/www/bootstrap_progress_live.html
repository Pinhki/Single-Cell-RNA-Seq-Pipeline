You are in a safe, standard setup

We are setting up the same native R and Python environment used by standard research workflows. This is the one-time foundation that makes your results reliable and reproducible.

  • Why this can feel slow: on first run, your computer may need to fetch many packages, build parts that are machine-specific, and verify that everything works together before analysis starts.
  • Can this be skipped? for a first clean setup, no. Most of the wait comes from the R/Python package ecosystem itself: unlike commercial apps, many community packages are not shipped as fully machine-validated bundles for every environment, so local build, compatibility tuning, and verification are required before analysis can run reliably. Completing this once gives you a stable environment that is reused on later launches.
  • Trusted foundation: this app uses standard, widely used R/Python packages and native runtime workflows, not experimental or untested tooling.
  • Reproducible across machines: package versions are pinned so analyses remain consistent across different computers and stay aligned with established published practices.
  • No risk to your current setup: installation runs in an isolated sandbox, so your existing R/Python environments and versions are not modified.
